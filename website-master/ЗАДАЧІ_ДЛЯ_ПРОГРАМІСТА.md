## ✅ Що вже зроблено в коді (гілка `claude/loving-thompson-35xq84`)

Наступні зміни вже внесені і знаходяться в гілці `claude/loving-thompson-35xq84`.
Потрібно зробити code review і злити в основну гілку (main/master).

1. Виправлено Schema.org Organization — прибрані заглушки (yourwebsite.com, американський телефон)
2. Створено динамічний sitemap.xml — збирає всі категорії, бренди, блоги, товари
3. Google Analytics більше не блокує завантаження сторінки
4. Додано JSON-LD розмітку Product на сторінки товарів (ціна, наявність, рейтинг)
5. Виправлено битий canonical URL на сторінках товарів (відсутній слеш між категорією і товаром)
6. Додано Open Graph теги (og:image, og:title) на головну і сторінки товарів
7. Головна сторінка більше не віддає 404 при тимчасовому падінні API
8. Перейменовані файли з кириличною літерою "С" в назві (CatalogСategories.tsx → CatalogCategories.tsx)
9. Прибрані дрібні помилки в коді (React.memo на серверних компонентах, невикористаний import)

## 🔴 Що потрібно зробити вручну на сервері (КРИТИЧНО)

### 1. Перевірити файл `.env` на production-сервері — ✅ ВЖЕ OK

Перевірено: на production запити йдуть на основний домен `footballshop.com.ua`.
Нічого міняти не потрібно. Шаблон правильних значень — у файлі `.env.example`
(на випадок переналаштування сервера).

### 2. Задеплоїти гілку `claude/loving-thompson-35xq84`

```bash
git checkout claude/loving-thompson-35xq84
npm run build
npm run start
# або через docker:
docker-compose -f docker-compose.prod.yml up --build -d
```

### 3. Після деплою — відправити sitemap в Google Search Console

- Зайти на: https://search.google.com/search-console
- Вибрати сайт footballshop.com.ua
- Зліва: Sitemap → Додати новий sitemap
- Ввести: `https://footballshop.com.ua/sitemap.xml`
- Натиснути "Надіслати"

## 🟡 Додаткові задачі (не термінові, але важливі)

### 4. Перевірити що sitemap.xml генерується правильно

Після деплою відкрити в браузері:
```
https://footballshop.com.ua/sitemap.xml
```
Має відображатися XML з усіма URL сайту.

### 5. Перевірити Schema.org розмітку на товарах

Відкрити будь-який товар через інструмент Google:
```
https://search.google.com/test/rich-results
```
Вставити URL товару. Має показати: Product, ціна, наявність.

### 6. Перевірити Core Web Vitals після деплою

```
https://pagespeed.web.dev/
```
Вставити https://footballshop.com.ua і перевірити показники LCP, CLS, FID.
